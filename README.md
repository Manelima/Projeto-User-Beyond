Esse foi o Projeto feito em mentoria da Beyond.Co no Programa Embarque Digital, 
aqui eu tive a oportunidade de aprender mais sobre desenvolvimento web, conceitos relacionadas ao Front-end e alguns outros serviços.

As Tecnologias utilizadas aqui foram: Vue.js como Framework de JS, Vuetify como UI Library, Node.js para simulação de Responsividade web utilizando do NPM (Node Package Manager) para orientar eventos de maneira Assíncrona,
 Firebase, dentro do Firebase: Cloud Firestore para armazenar os dados, Firebase Authentication para authenticação e cadastro de usuários com Email e Senha, e o para o CRUD Express.js
 
Esse foi meu primeiro contato com um Framework, já vi projetos de Companheiros de classe em Angular e React porém nunca tive contato com nenhum Framework (até de outras linguagens em funções diferentes).

Utilizando a versão do Vue 2 e Vuetify 2, o meu objetivo e "desafio" era criar um CRUD em uma das páginas que a empresa embarcada pediu, as páginas eram:
Cursos, Usuários, Calendário, Fórum e Biblioteca.


Fiquei com a parte de Usuários, a estilização na primeira versão era algo pessoal, porém como foi decidido coletivamente no processo de apresentação no laboratório do Porto Digital do Recife, 
decidimos o padrão cromático na palheta de indigo do Material Collors do Vuetify 2. 

O que de fato foi "novidade" pra mim e o que eu aprendi nesse projeto, tanto em tecnologias como em estruturação prefiro abordar em tópicos leves como um feedback traçando uma linha de raciocínio nesse readme juntamente com a funcionalidade do projeto.

ESTRUTURAÇÃO:

Na Estruturação das pastas do JS, como foi meu primeiro contato com Node.js e eu nunca mexi com JavaScript de fato (sendo o único contato o conhecimento breve da faculdade), 
geralmente eu baixava as dependecias e os node modules em uma pasta superior ou "fora" do diretório correto, fora alguns erros de import de arquivos, variavéis globais e scripts na linguagem.

Obviamente eu estava indo por conta própria, porém a praticidade e ensinamento dos professores da mentoria, que deixam as aulas gravadas inclusive foi essencial para eu entender e organizar,
assim como na Tríade Web padrão eu já separava em: Pasta de páginas com as páginas para um lado, pasta com os assets do outro, script do outro e a parte de style sheets separadas conforme a necessidade (ou as vezes deixava tudo em style.css).

Então após finalmente aprender a utilizar o terminal da IDE e aprender como utilizar o Git bash pedindo ajuda a meus companheiros de estudo e adquirindo conhecimento online, eu entendi e separei no projeto (assim como nas vídeo-aulas) os plugins, routes, 
configurações de import no firebase e suas divisões.
